# Panolive Frontend

This frontend is a React + Vite client for Panolive.

## Main features

- Account registration and login
- Role-aware dashboard for community members, repair experts, and administrators
- Item upload and AI suggestions
- Repair expert directory and connection requests
- Eco tips feed and administrator management pages

## Development

Install dependencies:

```bash
npm install
```

Start dev server:

```bash
npm run dev
```

Build production assets:

```bash
npm run build
```
